Como usar este projetoDemonstração e execução local
01

Explore os resultados

Percorra as quatro perspectivas. Os filtros alteram as tabelas; os indicadores descrevem o lote completo.

02

Execute a rotina

No projeto extraído, instale as dependências e execute o comando abaixo. Use uma pasta de saída vazia.

python -m pip install -r requirements.txt
python -m finance_close run --input sample-input/validado --controls config/controle.csv --period 2025-09 --output local-output/meu-fechamento
03

Confira as entregas

A rotina gera base aprovada, pendências, conciliação, rastreabilidade, JSON, Excel e HTML. O retorno 0 indica validado; 2 indica pendências; 1 indica erro na execução.
